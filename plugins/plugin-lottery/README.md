# 双色球实验室

仅在 Halo Console 后台展示的双色球历史分析插件。插件不调用外部 AI 服务，也不宣称能够改变随机开奖的理论概率。

## 功能

- 内置最近 100 期历史开奖样本（截至 2026-09-20）。
- 展示最近 30 期红、蓝球折线走势。
- 结合长期频率、近期热度、遗漏、趋势和号码结构生成 5 组候选。
- 用严格按时间顺序的滚动回测展示平均红球命中数、蓝球命中率和任意奖命中率。
- 所有算法权重和微调学习率均可在页面调整。
- 录入下一期真实开奖后，若未命中一等奖，则按真实号码与候选号码的特征差异小步微调权重。
- 支持批量导入历史数据以及 JSON 备份、恢复。
- 展示按组合数学计算的各奖级理论概率，并明确区分“模型分数”和“中奖概率”。

## 数据与隐私

初始数据来自[上海福彩数据中心](https://appsh.swlc.net.cn/shfcoc_datachart/datachart/ssq/lskj/ls_award.html)。后续开奖由管理员手动录入或批量导入。

开奖数据、模型参数和预测记录保存在当前浏览器的 `localStorage` 中，不会上传到第三方服务。更换浏览器或设备前请在“数据管理”中导出 JSON 备份。

批量导入格式（每行一期）：

```text
期号,开奖日期,红1,红2,红3,红4,红5,红6,蓝球
2026110,2026-09-22,01,05,09,16,22,31,08
```

## 构建

环境要求：Java 21、Node.js 22+、pnpm 10+。

```powershell
.\gradlew.bat clean build
```

构建产物位于 `build/libs/`。

## 重要说明

双色球每期开奖相互独立。历史频率、遗漏、趋势、回测结果和在线微调都不能提高任意一注的理论中奖概率；页面生成内容只用于统计实验和娱乐，不构成购彩建议。
